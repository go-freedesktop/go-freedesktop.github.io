# go-freedesktop.github.io

Source for the **go-freedesktop** organization landing page at
<https://go-freedesktop.github.io/>, built with [Hugo](https://gohugo.io/)
(self-contained layouts, no theme). Pushes to `main` build and deploy to
GitHub Pages via `.github/workflows/hugo.yml`.

```sh
hugo server   # local preview
```
